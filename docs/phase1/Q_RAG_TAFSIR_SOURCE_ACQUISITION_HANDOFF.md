# Tafsir Source Acquisition Handoff

این سند دقیقاً مشخص می‌کند برای باز کردن Gate NB07 چه چیزی لازم است.

## برای هر تفسیر
یک Source package لازم است که شامل این‌ها باشد:
- عنوان و مؤلف
- زبان نسخه
- Edition/Publisher/Year در صورت وجود
- URL یا محل دریافت
- Evidence حقوق/اجازه استفاده
- فایل Raw یا Structured snapshot
- SHA-256
- Locator پایدار
- نگاشت سوره و بازه آیه
- نمونه Manual review

## اولویت
1. المیزان — نسخه فارسی یا عربی قابل استناد
2. تسنیم — نسخه فارسی معتبر
3. نمونه — نسخه فارسی معتبر
4. نورالثقلین — نسخه عربی روایی
5. البرهان — نسخه عربی روایی

## وضعیت فعلی
- Al-Mizan: یک digitization انگلیسی در Al-Islam کشف شده، اما نسخه هدف فارسی/عربی هنوز Freeze نشده.
- Tasnim: endpoint ماشین‌خوان معتبر هنوز Freeze نشده.
- Nemuneh: endpoint ماشین‌خوان معتبر هنوز Freeze نشده.
- Nur al-Thaqalayn: چند Candidate دیجیتال/اسکن کشف شده؛ حقوق و edition target باید انتخاب شود.
- Al-Burhan: Candidateهای دیجیتال/اسکن کشف شده؛ حقوق و edition target باید انتخاب شود.

هیچ‌یک در پایان Wave 05 Active Corpus نیستند.
