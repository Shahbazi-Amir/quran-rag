# Quran text source and attribution note

The Phase 1 Quran candidate is documented as originating from the Tanzil Project.

Official source evidence recorded by this repository states that Tanzil Quran Text is distributed under Creative Commons Attribution 3.0 for verbatim copying/distribution, with attribution and a link back to Tanzil required. The Quran text must not be modified under those terms.

Canonical ingestion in QRAG therefore preserves the accepted Arabic verse text verbatim. Normalized search forms, if created later, must be stored as separate derived fields and must never replace or be presented as the canonical text.

Evidence URLs are stored in:
`data/phase1/source_evidence/quran_tanzil_source_evidence_v1.json`
